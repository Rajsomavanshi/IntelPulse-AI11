UPGRADE INTELPULSE AI INTO A JUDGE-READY AUTONOMOUS COMPETITIVE INTELLIGENCE AGENT.

This is a hackathon project. The Tool Calling requirement is extremely important.

"Integrate at least 2 external tools/APIs relevant to the problem. The agent should dynamically determine when and which tool to use."

Do NOT merely create placeholder functions. Implement a real, demonstrable agentic tool-calling workflow.

==================================================
1. CORE CONCEPT
==================================================

Turn IntelPulse AI into an "AI Competitive Intelligence Investigator".

The user gives one strategic question.

Example:

"Analyze NVIDIA's position in AI semiconductors."

The AI agent should:

1. Understand the objective.
2. Break the objective into investigation tasks.
3. Decide which tools are necessary.
4. Call only the relevant tools.
5. Collect evidence.
6. Cross-check information where possible.
7. Identify trends.
8. Detect threats.
9. Detect opportunities.
10. Generate strategic recommendations.
11. Show the evidence and sources used.

The agent must dynamically select tools.

==================================================
2. INTEGRATE THESE 4 EXTERNAL TOOLS
==================================================

Implement these four tools because they provide a strong and easy-to-understand hackathon demonstration.

TOOL 1 — NEWS / WEB INTELLIGENCE

Purpose:
Find recent competitor announcements, market activity, product launches, partnerships, investments, and industry developments.

Use a reliable news/web search API such as:
- Tavily Search API
OR
- another reliable web/news search API already supported by the project.

Tool name:

search_news_and_web

Inputs:
- query
- recency
- domains (optional)

Output:
- title
- source
- URL
- publication date
- short summary
- relevance score

==================================================

TOOL 2 — RESEARCH INTELLIGENCE

Purpose:
Find scientific papers and research developments.

Use OpenAlex or Crossref API.

Tool name:

search_research

Inputs:
- topic
- author (optional)
- organization (optional)
- date range

Output:
- paper title
- authors
- publication date
- journal/source
- DOI/URL
- abstract/summary when available
- relevance

==================================================

TOOL 3 — PATENT INTELLIGENCE

Purpose:
Find patent activity related to technologies and competitors.

Use a legitimate public patent API such as PatentsView or another appropriate patent API.

Tool name:

search_patents

Inputs:
- company
- technology
- keywords
- date range

Output:
- patent/application title
- applicant/assignee
- inventors when available
- filing/publication date
- patent URL/identifier
- short description

==================================================

TOOL 4 — GITHUB / DEVELOPER INTELLIGENCE
==================================================

Use the GitHub REST API.

Tool name:

analyze_github_activity

Purpose:
Analyze public development activity around companies, organizations, technologies, and competitors.

Retrieve useful signals such as:

- repositories
- recent commits
- releases
- stars
- forks
- contributors
- repository activity
- technology topics

Example:

If the user asks about AI infrastructure competitors, the agent can investigate relevant public GitHub activity.

3. DYNAMIC TOOL SELECTION
==================================================

THIS IS THE MOST IMPORTANT PART.

The agent MUST decide which tools to call.

Do NOT automatically call all four tools for every question.

Create a planner/router.

Example:

Question:
"Show me recent NVIDIA announcements."

Agent decision:

News tool → REQUIRED
Research → NOT REQUIRED
Patent → NOT REQUIRED
GitHub → NOT REQUIRED

"What are the latest AI semiconductor research trends?"

Agent decision:

Research → REQUIRED
News → OPTIONAL
Patent → OPTIONAL
GitHub → NOT REQUIRED

Question:
"Analyze NVIDIA's competitive position in AI chips."

Agent decision:

News → REQUIRED
Research → REQUIRED
Patent → REQUIRED
GitHub → OPTIONAL

Question:
"Compare NVIDIA and AMD developer activity."

Agent decision:

GitHub → REQUIRED
News → OPTIONAL
Research → OPTIONAL
Patent → NOT REQUIRED

The UI must visibly show these decisions.
