Build a Production-Ready Agentic AI Competitive Intelligence Platform

Build a complete, deployable web application called IntelPulse AI.

1. Problem

Organizations, startups and research institutions need to continuously monitor:

- Scientific research
- Patents
- Competitor activity
- Industry news
- Technology trends

Manually monitoring these sources is slow and causes important developments to be missed.

Build an autonomous AI agent that turns these fragmented information sources into concise, prioritized and actionable competitive intelligence.

2. Core requirement

This MUST be a real Agentic AI application, not a simple chatbot.

The agent must follow this workflow:

USER GOAL
→ Understand objective
→ Create plan
→ Select appropriate tools
→ Execute searches
→ Collect information
→ Analyze information
→ Cross-check important claims
→ Detect trends/threats/opportunities
→ Prioritize findings
→ Generate actionable recommendations

The UI should make this agentic workflow visible to the user.

5. Agent behavior

The agent MUST be capable of multi-step reasoning and tool selection.

Example:

User asks:

"Monitor autonomous driving competitors."

The agent should determine that it needs to:

1. Identify relevant competitors.
2. Search research publications.
3. Search patent activity.
4. Search recent news.
5. Remove duplicate information.
6. Compare developments.
7. Identify significant changes.
8. Verify important findings.
9. Score their impact.
10. Identify opportunities and threats.
11. Generate recommendations.

Do not hard-code this exact sequence if the agent can intelligently determine which tools are necessary.

6. Verification

Do not blindly trust a single source.

For important findings:

- Prefer reliable sources.
- Store the source URL.
- Compare multiple sources where possible.
- Clearly indicate confidence.
- Never fabricate citations or sources.
- If information cannot be verified, say so.

Implement the Tool Calling requirement for IntelPulse AI.

The agent MUST integrate at least 2 external tools/APIs that are directly relevant to competitive intelligence.

Use these tools:

1. Research/News Search API
   - Search for recent industry news, competitor announcements, technology developments, and research-related information.
   - The agent should decide when a news/research search is necessary.

2. Patent Search API
   - Search for relevant patent developments, patent filings, inventors, organizations, and technology areas.
   - The agent should decide when patent information is relevant to the user's investigation.

Implement these as actual callable tools available to the AI agent.

IMPORTANT:
The agent must NOT blindly call every tool.

It must dynamically determine:
- What information the user is requesting.
- Which tool is relevant.
- When to call the tool.
- Whether one tool or multiple tools are required.
- What parameters/query should be sent to each tool.
- How to combine the returned information.

Example:

If the user asks:
"Find recent competitor announcements about NVIDIA"

The agent should primarily use the News/Research Search tool.

If the user asks:
"Find recent patents related to AI semiconductor chips"

The agent should use the Patent Search tool.

If the user asks:
"Analyze NVIDIA's recent competitive activity, patents, and technology developments"

The agent should intelligently use BOTH tools and combine their results.
